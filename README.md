# Abrar Daiyan Khan

Data science student at UNC Charlotte. I turn messy data into analysis people can act on: forecasting models, validation done properly, and apps that make the results usable.

## Featured work

**Royale IQ**: a live Clash Royale analytics site (players, decks and cards) built on battle data and the game's official API. A showcase repo with the architecture and screenshots is coming.

**NYC Air Pollution, Forecasting and Environmental Justice**: co-authored study of PM2.5, NO2 and Ozone across NYC's UHF42 neighborhoods, 2009-2023.
- Random Forest reached R² 0.98 on a held-out 2023 test set, with time-series cross-validation (R² 0.96) so the model never trains on the future.
- K-Means on census demographics plus pollution surfaced high-poverty Bronx neighborhoods with elevated NO2.

**[Clash Royale Battle Explorer](https://github.com/akhan69-hash/DTSC-3601)**: Streamlit and Plotly EDA app over 20,000 battles.

**[Card Select](https://github.com/akhan69-hash/card-select)**: Next.js card explorer with a draggable 3D card and interactive insights charts.
